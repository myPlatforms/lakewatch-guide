2. Lakewatch 켜기

2단계 - Lakewatch 켜기

워크스페이스 관리자가 Previews 페이지에서 Lakewatch Beta를 켜고, 앱 전환기로 Lakewatch를 처음 엽니다. Lakewatch는 워크스페이스 사이드바에 나오지 않고 앱 전환기에만 있습니다.

근거 문서: 워크스페이스용 Lakewatch 설정 (opens in a new tab)

학습 목표

  1. Previews 페이지에서 Lakewatch Beta의 상태를 확인하고 켠다
  2. 앱 전환기에서 Lakewatch를 연다
  3. Lakewatch 상단 막대의 구성 요소를 구분한다

A. Previews에서 Lakewatch Beta 켜기

이 작업은 워크스페이스 관리자만 할 수 있습니다.

  1. 워크스페이스 오른쪽 위의 프로필 아이콘을 누르고 Previews를 선택합니다.
  2. Filter previews 입력란에 Lakewatch를 입력합니다.
  3. Lakewatch 항목(Beta)의 토글을 On으로 바꿉니다.

항목 설명은 "Enable Lakewatch security and event management in the app switcher for this workspace."입니다. 페이지 안내에 따르면 Preview를 켜거나 끈 변경은 몇 분 뒤에 반영됩니다.

ℹ️

검증 환경의 상태
검증 워크스페이스는 이 항목이 이미 On이었습니다. 그래서 토글을 직접 바꾸지는 않았고, 켜진 상태의 화면만 확인했습니다.

⚠️

워크스페이스 전체에 적용됩니다
이 Preview를 켜면 워크스페이스의 모든 사용자의 앱 전환기에 Lakewatch가 나타납니다. 접근할 수 있는 환경이 없는 사용자가 Lakewatch를 열면 Welcome to Lakewatch 설정 화면이 나타납니다.

완료 기준: Previews 페이지에서 Lakewatch 항목이 On입니다.

B. 앱 전환기에서 Lakewatch 열기

  1. 워크스페이스 오른쪽 위의 앱 전환기(점 9개 아이콘)를 누릅니다.
  2. 목록에서 Lakewatch (Security and event management)를 선택합니다.

목록에 Lakewatch가 없으면 A를 다시 확인하고 몇 분 뒤에 새로 고칩니다.

환경이 아직 하나도 없으면 Welcome to Lakewatch 화면이 열립니다. 주소는 /lakewatch/welcome입니다. 환경은 반드시 있어야 하므로 이 설정은 건너뛸 수 없고, 누군가 설정을 마친 뒤에는 바로 Lakewatch로 들어갑니다.

C. 상단 막대 살펴보기

Lakewatch 화면 오른쪽 위에는 아래 항목이 있습니다.

항목내용
Beta 토글Lakewatch Beta 화면을 쓰는 스위치입니다. 검증 환경에서는 "Classic Lakewatch is not available in this workspace." 안내가 붙어 있었습니다. 그대로 둡니다
Environment, workspace and compute환경(카탈로그), 워크스페이스, SQL 웨어하우스를 고릅니다 (1단계 B2)
Preferences개인 환경 설정 (이 가이드에서는 다루지 않습니다)
Genie Code어느 페이지에서든 Genie Code 패널을 엽니다
앱 전환기워크스페이스나 다른 앱으로 돌아갑니다

완료 기준: Lakewatch가 열리고 Welcome to Lakewatch 화면(또는 이미 환경이 있으면 Overview)이 보입니다.
