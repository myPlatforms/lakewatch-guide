# Lakewatch 구성·실습 가이드 (한국어, 비공식)

사이트: https://myplatforms.github.io/lakewatch-guide/

Databricks Lakewatch(Beta)를 워크스페이스에 구성하고, 가상의 보안 사고를 조사하는 실습으로 익히는 한국어 가이드입니다.

- Databricks 공식 문서가 아닙니다. 최신 내용은 [Lakewatch 공식 문서](https://docs.databricks.com/aws/en/lakewatch/)에서 확인하세요.
- Lakewatch는 Beta 단계라 화면과 동작이 바뀔 수 있습니다. 가이드의 기준일은 사이트 첫 페이지에 적혀 있습니다.
- 이 리포에는 빌드된 정적 사이트 파일만 있습니다.
